# Magic In White

Revamped website for Magic In White — Integrated Creative Studio.

Static site (no build step): `index.html`, `team.html`, `css/`, `js/`, `assets/`.
Uses GSAP + ScrollTrigger and Lenis from CDN; images are served from the studio's ImageKit account.

Run locally:

    python -m http.server 8000

then open http://localhost:8000
